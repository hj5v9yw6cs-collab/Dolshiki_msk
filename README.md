# Dolshiki_msk

Автоматизация процессов юридической компании по защите прав дольщиков
(Казань / Москва / СПб).

## Состояние

| Фаза | Модуль | Статус |
|---|---|---|
| 1 | Калькулятор неустойки по 214-ФЗ, приём заявок | **готово** |
| 2 | CRM-ядро: воронка дел, карточка дела, сроки, роли | не начато |
| 3 | Документооборот: приём, классификация, реестр в Excel | не начато |
| 4 | Генерация претензий и исков по шаблонам | не начато |
| 5 | Сайт и лендинги услуг, SEO | не начато |

## Быстрый запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements-dev.txt

cd backend
ADMIN_TOKEN=dev-token ../.venv/bin/uvicorn app.main:app --reload --port 8000
```

Калькулятор — http://localhost:8000/widget/index.html, API — http://localhost:8000/docs

Тесты: `cd backend && ../.venv/bin/python -m pytest -q`


## Три правила проекта

1. **Юридические параметры живут в конфиге, а не в коде.** Ставки ЦБ, мораторные
   периоды и размеры штрафов меняются постановлениями правительства. Каждый параметр
   несёт ссылку на основание и флаг `requires_lawyer_review`; пока флаг стоит, расчёт
   сопровождается предупреждением.
2. **Автоматически сгенерированный документ — черновик.** Претензия, иск и расчёт
   помечаются как требующие проверки юристом до подачи.
3. **Персональные данные — по 152-ФЗ.** Паспорта и ДДУ обрабатываются на серверах в
   РФ, с фиксацией согласия и разграничением доступа. См. `SECURITY.md`.

## Важно про цифры в конфиге

Значения в `backend/config/legal-config.json` — рабочий черновик: история ключевой
ставки, периоды мораториев (ПП РФ № 479, № 326 и его продление) и размер штрафа
внесены как заготовка и **требуют сверки юристом с первоисточниками**. Система об этом
предупреждает на каждом расчёте, пока флаги `requires_lawyer_review` не сняты.
