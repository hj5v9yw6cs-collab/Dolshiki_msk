# Как запустить бесплатно

Три шага, каждый следующий — необязательный. Первый даёт пользу уже сегодня
и не стоит ничего.

## Шаг 1. Калькулятор на example.ru — 0 ₽

`site/dist/calculator.html` — один файл, которому не нужен ни сервер, ни база.
Он считает прямо в браузере посетителя.

**Что сделать:**

1. Откройте `site/config.js`, впишите свой номер WhatsApp и телефон:

   ```js
   window.SITE_CONTACT = {
     whatsapp: "79171234567",           // без плюса и пробелов
     phone: "+7 917 123-45-67",
     telegram: "",
     policy_url: "https://ваш-домен.ru/policy"
   };
   ```

2. Пересоберите файл:

   ```bash
   ./.venv/bin/python site/build.py
   ```

3. Залейте `site/dist/calculator.html` на хостинг example.ru — туда же, где
   лежат остальные страницы. Получится адрес вида
   `https://ваш-домен.ru/calculator.html`.

4. Поставьте ссылку на него в меню сайта.

**Как это работает для клиента:** посчитал → увидел сумму → заполнил имя и
телефон → нажал кнопку → открылся WhatsApp с готовым сообщением:

> Здравствуйте! Считал на сайте по 214-ФЗ.
> Неустойка за просрочку передачи: 2 174 725,00 ₽.
> Период: 31.12.2021 — 15.09.2025, засчитано 430 дней.
>
> Меня зовут: Иван Петров
> Телефон: +7 900 111-22-33
> Объект: ЖК Символ

**Чего здесь нет:** заявки не складываются в базу — они приходят в WhatsApp.
При 30 делах в месяц это рабочая схема; терять заявки вы начнёте, когда
поток вырастет в разы.

## Шаг 2. Рабочий кабинет на офисном компьютере — 0 ₽

Кабинет с делами можно держать на любом компьютере в офисе. Данные лежат
на этом компьютере, в России — требование 152-ФЗ соблюдается.

```bash
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt

cd backend
ADMIN_TOKEN=придумайте-длинную-строку ../.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Заведите сотрудников:

```bash
./.venv/bin/python backend/scripts/create_user.py boss@example.ru "Фёдор Ильин" manager
./.venv/bin/python backend/scripts/create_user.py irina@example.ru "Ирина Соколова" lawyer
```

Кабинет открывается по адресу `http://<адрес-компьютера>:8000/app/`.
Коллеги в том же офисе заходят по локальной сети — узнать адрес можно
командой `ipconfig` (Windows) или `ifconfig` (Mac).

**Что обязательно делать:** раз в день копировать файл `backend/data/app.db`
на флешку или в облако. Это вся база. Сломается компьютер — с копией вы
теряете день работы, без копии — всё.

**Ограничения:** работает, только пока компьютер включён. Из дома и с
телефона вне офиса не зайти.

## Шаг 3. Доступ снаружи — 0 ₽

Если нужно заходить в кабинет из дома и с телефона, не покупая сервер:
бесплатный туннель (например, Cloudflare Tunnel) даёт вашему офисному
компьютеру постоянный адрес в интернете. Данные при этом остаются
в офисе — наружу выставляется только доступ.

Перед этим шагом стоит спросить юриста: через туннель проходит трафик
с персональными данными, и в вашем случае это лучше зафиксировать в
документах по обработке ПДн.

## Когда пора платить

Переезжать на сервер за 1–2 тысячи в месяц имеет смысл, когда совпадёт
хотя бы два пункта:

- надоело зависеть от включённого компьютера;
- в системе появились документы клиентов (паспорта, ДДУ) и нужны
  настоящие резервные копии, а не флешка;
- заявок стало столько, что терять их в переписке дорого;
- сотрудники работают из разных городов.

До этого момента бесплатный вариант честно закрывает задачу.
