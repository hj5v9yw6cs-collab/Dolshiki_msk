# Установка на сервер

Пошагово, без предположений о технических знаниях. Всё вместе занимает
примерно час. Если будете нанимать админа — этой страницы ему достаточно.

## Хостинг или сервер — это разные вещи

Прежде чем покупать, проверьте, что у вас уже есть.

**Обычный хостинг** (его же называют виртуальным или shared) — это место
под файлы сайта. Обычно рассчитан на PHP: WordPress, Битрикс, готовые
CMS. Свою программу там запустить нельзя — хостинг просто отдаёт файлы
браузеру. Стоит 150–400 ₽ в месяц.

**Виртуальный сервер (VPS)** — отдельная машина, на которой вы ставите
что угодно и запускаете постоянно работающие программы. Стоит
800–1500 ₽ в месяц.

Наша система написана на Python и работает как постоянный процесс:
считает, ведёт базу, принимает файлы. **Ей нужен VPS.** На обычном
хостинге она не запустится.

**Как проверить, что у вас:**

- В панели управления есть раздел «Виртуальные серверы», «VPS» или
  «Облачные серверы», и там что-то заведено → у вас сервер.
- Есть только «Сайты», «Файловый менеджер», «Базы данных MySQL»,
  «PHP-версия» → это обычный хостинг, сервер нужно докупить.
- Есть доступ по SSH с правами root → почти наверняка сервер.

**Если сервера нет**, VPS покупается в той же панели, где у вас домен,
за пару минут — переносить домен никуда не нужно.

**Если менять ничего не хотите**, на обычном хостинге можно разместить
только калькулятор одним файлом: см. `BESPLATNO.md`. Сайт, кабинет и
работа с документами так работать не будут.

## Что понадобится

1. **Сервер в России.** Selectel, Timeweb, RuVDS, VK Cloud, Яндекс Облако.
   Минимум: 1 ядро, 1 ГБ памяти, 20 ГБ диска, Debian или Ubuntu.
   Комфортно: 2 ГБ памяти. Ориентир — 300–900 ₽ в месяц.

   Сколько мы реально едим: приложение держится на **78 МБ**, плюс
   Caddy и Docker — итого около **300 МБ**. На 1 ГБ работает, но запас
   небольшой, поэтому на таком тарифе **обязательно включите подкачку**
   (см. шаг 1). На 2 ГБ подкачка не нужна.
2. **Домен `dolshikirf.ru`.** В настройках домена сделайте A-запись
   на IP-адрес сервера. Если домен уже указывает на старый хостинг,
   запись нужно переставить на сервер.
3. **Одного домена достаточно.** Сайт открывается на `dolshikirf.ru`,
   кабинет для сотрудников — на `dolshikirf.ru/app/`. Отдельный поддомен
   заводить не нужно, а от поиска кабинет закрыт файлом robots.txt.

## Шаг 1. Подготовить сервер

Подключитесь к серверу по SSH и выполните:

```bash
# Docker — среда, в которой запускается система
curl -fsSL https://get.docker.com | sh

# Подкачка на 2 ГБ — страховка для сервера с 1 ГБ памяти.
# Без неё редкий тяжёлый запрос может уронить приложение.
fallocate -l 2G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab

# Забираем код
git clone https://github.com/hj5v9yw6cs-collab/dolshiki_msk.git /opt/dolshiki
cd /opt/dolshiki
```

## Шаг 2. Настроить

Два файла с настройками.

**`backend/.env`** — параметры приложения:

```bash
cp backend/.env.example backend/.env
nano backend/.env
```

Обязательно поменяйте `ADMIN_TOKEN` на длинную случайную строку.
Сгенерировать: `openssl rand -base64 32`

Впишите домены сайта, чтобы калькулятор с них работал:

```
ADMIN_TOKEN=сюда-длинную-случайную-строку
CORS_ORIGINS=https://dolshikirf.ru,https://www.dolshikirf.ru
```

**`deploy/.env`** — домен самой системы:

```bash
cp deploy/.env.example deploy/.env
nano deploy/.env
```

```
DOMAIN=dolshikirf.ru
```

## Шаг 3. Запустить

```bash
cd /opt/dolshiki/deploy
docker compose up -d
```

Через минуту система будет доступна по адресу `https://dolshikirf.ru`.
Сертификат HTTPS выпускается автоматически, ничего настраивать не нужно.

Проверить, что всё поднялось:

```bash
docker compose ps
curl https://dolshikirf.ru/health
```

## Шаг 4. Завести сотрудников

```bash
cd /opt/dolshiki/deploy
docker compose exec app python scripts/create_user.py boss@dolshikirf.ru "Фёдор Ильин" manager
docker compose exec app python scripts/create_user.py irina@dolshikirf.ru "Ирина Соколова" lawyer
```

Пароль спрашивается при вводе и в истории команд не сохраняется.
Роли: `manager` — руководитель, видит деньги; `lawyer` — юрист.

Кабинет: `https://dolshikirf.ru/app/`

## Шаг 5. Поставить калькулятор на сайт

Сайт уже входит в систему и открывается на `dolshikirf.ru` — калькулятор
встроен в страницы про неустойку и недостатки, вставлять ничего не нужно.

Две строки ниже нужны, только если вы захотите показать калькулятор на
каком-то стороннем сайте или лендинге:

```html
<div id="garant-calc"></div>
<script src="https://dolshikirf.ru/embed.js"
        data-target="garant-calc"
        data-policy-url="https://dolshikirf.ru/policy"></script>
```

Открыть сразу на нужном сценарии: добавьте `data-mode="defects"` для
недостатков отделки или `data-mode="delay"` для просрочки.

Заявки с калькулятора начнут падать в кабинет, во вкладку «Заявки».
Оттуда дело заводится одной кнопкой.

## Шаг 6. Автоматические задачи

```bash
crontab -e
```

Вставьте строки из `deploy/crontab.example`:

```
0 6 * * *  cd /opt/dolshiki/deploy && docker compose exec -T app python scripts/sync_rates.py >> /var/log/dolshiki-cbr.log 2>&1
0 3 * * *  /opt/dolshiki/deploy/backup.sh daily >> /var/log/dolshiki-backup.log 2>&1
0 4 * * 0  /opt/dolshiki/deploy/backup.sh full  >> /var/log/dolshiki-backup.log 2>&1
```

Первая обновляет ключевую ставку ЦБ. Две другие делают копии, и они
разные по назначению:

- **daily** — база и юридический конфиг. Меняются каждый день, весят
  килобайты. Хранится 30 копий.
- **full** — то же плюс файлы дел: паспорта, ДДУ, заключения экспертов.
  Меняются редко, весят много. Хранится 4 копии.

**Проверьте обе копии руками сразу после установки:**

```bash
/opt/dolshiki/deploy/backup.sh daily
/opt/dolshiki/deploy/backup.sh full
ls -lah /var/backups/dolshiki
```

Скрипт сам проверяет, что архив читается и что база внутри есть; если
нет — пишет ошибку и удаляет пустышку.

**Копии лежат на том же сервере.** Пропадёт сервер — пропадут и они.
Раз в неделю забирайте полный архив к себе:

```bash
scp root@АДРЕС_СЕРВЕРА:/var/backups/dolshiki/dolshiki-full-*.tar.gz .
```

**Про диск.** Документы — единственное, что заметно растёт: при 30 делах
в месяц это примерно 1–2 ГБ в год. Плюс четыре полные копии. На 20 ГБ
хватит на два-три года; следите за строкой «Свободно на диске» в конце
каждой записи журнала бэкапа.

## Шаг 7. Уведомления в Telegram (необязательно)

Чтобы заявки приходили в Telegram:

1. Напишите `@BotFather`, создайте бота, получите токен.
2. Добавьте бота в чат, узнайте ID чата.
3. Впишите в `backend/.env`:

```
TELEGRAM_BOT_TOKEN=токен-от-BotFather
TELEGRAM_CHAT_ID=id-чата
```

4. `docker compose up -d` — перезапустится с новыми настройками.

Если не настраивать, заявки всё равно сохраняются в базу и видны в кабинете.

## Обновление системы

```bash
cd /opt/dolshiki
git pull
cd deploy
docker compose up -d --build
```

База и правки юриста в конфиге лежат в отдельных томах и при обновлении
не затрагиваются.

## Восстановление из копии

```bash
cd /opt/dolshiki/deploy
docker compose down
mkdir -p /tmp/restore && tar -xzf /var/backups/dolshiki/dolshiki-ДАТА.tar.gz -C /tmp/restore
docker compose run --rm -v /tmp/restore:/restore app sh -c "cp /restore/app.db data/app.db && cp -r /restore/config/. config/"
docker compose up -d
```

## Про базу данных

По умолчанию используется SQLite — вся база лежит в одном файле. При
четырёх сотрудниках и 30 делах в месяц этого достаточно с большим
запасом, а резервное копирование сводится к копированию одного файла.

Если когда-нибудь понадобится PostgreSQL, менять код не нужно: достаточно
прописать в `backend/.env` строку подключения:

```
DATABASE_URL=postgresql+psycopg://пользователь:пароль@адрес:5432/база
```

## Чего в этой сборке нет

Названо честно, чтобы не всплыло при установке:

- **Образ Docker не собирался в среде разработки** — доступ к Docker Hub
  оттуда закрыт. Файлы стандартные и проверены на синтаксис, но первую
  сборку `docker compose up -d --build` вы увидите вживую сами.
- **Почтовых уведомлений нет** — только Telegram. Почта появится, когда
  понадобится отправлять письма клиентам.
- **Мониторинга нет.** Если система упадёт, вы узнаете об этом, когда
  зайдёте. При таком размере это приемлемо, но помните об этом.
